# Incident Report INC-2026-353

Kestrel Instruments. Internal use only.

## Summary

Incident INC-2026-353 interrupted measurements at Kronborg Foods AB and was handled by customer support together with engineering.

Incident INC-2026-353 occurred on 27 February 2026 at Kronborg Foods AB. The affected product was the Kestrel KV9 and the incident was classified as severity 2.

## Cause

Root cause analysis identified a corroded connector.

## Contributing factors

- Spare devices were not available on site
- Documentation of the installation was incomplete
- The affected installation was not on the latest firmware

## Measures

| Action | Owner | Status |
|---|---|---|
| Ship the fix with firmware 1.2.8 | Engineering | done |
| Review spare part stock for key customers | Logistics | done |
| Roll out the fix to all affected installations | Engineering | in progress |
| Update the installation checklist | Quality | in progress |
| Share lessons learned in the engineering forum | Engineering | open |

The fix shipped with firmware 1.2.8.
