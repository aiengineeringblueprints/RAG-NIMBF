# Project Brief PRJ-201: Arctic Automation Expansion

Kestrel Instruments, internal document.

## Introduction

Project PRJ-201, Arctic Automation Expansion, is delivered for Kolbu Mining AS.

Kolbu Mining AS commissioned project PRJ-201 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

Project PRJ-201 replaces manual readings with continuous monitoring, so that Kolbu Mining AS can react to deviations faster.

## Project facts

- Project code: PRJ-201
- Customer: Kolbu Mining AS
- Project lead: Niklas Vestergaard
- Delivery site: Houston
- Product: Kestrel KP8
- Start date: 2025-04-13
- Final deadline: 2026-01-07

The project is led by Niklas Vestergaard and run from the Houston site. The solution is based on the Kestrel KP8.

## Financials

The initial estimate was 100500 EUR. After the scope review the steering committee approved a budget of 75000 EUR.

## Scope of delivery

Project PRJ-201 includes training for the customer's maintenance staff and a documentation package for audits.

Civil works and cabling outside the measuring points are not part of project PRJ-201 and are provided by Kolbu Mining AS.
