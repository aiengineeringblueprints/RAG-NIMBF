# KQ Series Firmware Release Notes (power quality meters)

Kestrel Instruments, internal document.

## Introduction

The KQ series shares one firmware code base, but each model receives its own signed image. Images cannot be exchanged between models.

These release notes list the firmware history of the KQ series. Install the latest release unless a project specification requires a validated older version.

Firmware for the KQ series is cumulative: every release contains all fixes of the earlier releases. Downgrades are possible but not recommended.

## Known issues

- Remote configuration backups fail on networks with very high latency.
- The event list is cleared after a factory reset.

## Security

Kestrel recommends restricting network access to KQ devices to the control network and changing default user codes during commissioning.

Releases of the KQ series are signed, and devices reject images with an invalid signature. Report suspected vulnerabilities to the Kestrel product security team.

Security fixes for the KQ series are announced through the service portal and the customer newsletter.

## Update procedure

Plan updates of KQ devices for maintenance windows, because measurements are interrupted while the new image is activated.

If an update of a KQ device fails, the previous image stays active and the update can be repeated. Roll back through the service portal if necessary.

Download the firmware image for the KQ series from the Kestrel service portal and verify the signature before distributing it.

Devices of the KQ series keep their configuration during an update. Create a configuration backup anyway before updating devices in the field.

## Compatibility

Configuration backups created with older KQ firmware can be restored on newer releases; the reverse direction is not supported.

All releases of the KQ series work with the current Kestrel Configurator. Older configurator versions can read but not write settings of the latest firmware.

Firmware releases of the KQ series keep the communication register map stable, so control system integrations do not need changes after an update.
