# KT Series Firmware Release Notes (temperature probes)

Owner: Kestrel Instruments. Classification: internal.

## Scope of this document

These release notes list the firmware history of the KT series. Install the latest release unless a project specification requires a validated older version.

Firmware for the KT series is cumulative: every release contains all fixes of the earlier releases. Downgrades are possible but not recommended.

## Security

Security fixes for the KT series are announced through the service portal and the customer newsletter.
