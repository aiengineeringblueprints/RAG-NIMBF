# Code of Conduct

Kestrel Instruments. Internal use only.

## Purpose

This document describes the rules of the Code of Conduct at Kestrel Instruments and explains why they exist. It gives employees and managers a common reference for daily decisions.

The Code of Conduct protects employees, customers and the company by setting clear and fair expectations. It applies equally at every Kestrel site.

The Code of Conduct turns legal requirements and company values into practical rules. Where local law sets stricter requirements, local law takes precedence.

## Background

The Code of Conduct is reviewed together with employee representatives, so that changes are understood and accepted.

Audits and legal requirements also influenced the Code of Conduct, which therefore uses clear and verifiable rules.

Feedback from employees and managers shaped the current Code of Conduct; it aims to be simple to apply and fair for everybody.

## Who this applies to

Managers are responsible for making sure that their teams know the Code of Conduct and apply it.

Temporary staff and interns follow the Code of Conduct in the same way as permanent employees.

The Code of Conduct applies to all employees and contractors of Kestrel Instruments unless a local works agreement states otherwise.

## Terms used

- **Intranet**: the internal information portal of Kestrel Instruments
- **Manager**: an employee with formal responsibility for a team or cost center
- **Site**: any office, plant, lab or warehouse operated by Kestrel Instruments
- **Contractor**: a person working for Kestrel through a service agreement
- **Employee**: a person with an employment contract with Kestrel Instruments

## Policy statements

1. Gifts from business partners above 50 EUR must be declined.
2. Conflicts of interest are disclosed to the Compliance Officer.
3. Every employee completes the code of conduct training once a year.

## Frequently asked questions

**Q:** What happens if the Code of Conduct conflicts with local law?
**A:** Local law always takes precedence, and HR documents the deviation.

**Q:** Who answers questions about the Code of Conduct?
**A:** Your manager is the first contact; HR helps with questions the manager cannot answer.

**Q:** Are earlier versions of the Code of Conduct still valid?
**A:** No. Earlier versions are archived for audit purposes only and must not be applied.

**Q:** Where can I find the current version of the Code of Conduct?
**A:** The current version is always published on the intranet; printed copies may be outdated.

## Procedure

1. Submit the request through the HR portal
2. Attach the required documents
3. Read the relevant section of the Code of Conduct before starting the process

## Contacts

The intranet page of the Code of Conduct lists the responsible HR contact for each site.

For urgent questions about the Code of Conduct outside office hours, contact the duty manager of your site.

## Deviations

Repeated or deliberate violations of the Code of Conduct can lead to disciplinary measures.

Approved exceptions to the Code of Conduct are documented and reviewed when the policy is updated.

Exceptions to the Code of Conduct require written approval from the responsible manager and HR.

## Responsibilities

Managers apply the Code of Conduct consistently and document exceptions they approve.

The document owner of the Code of Conduct reviews it regularly and publishes changes on the intranet.

Employees follow the Code of Conduct and ask their manager or HR when something is unclear.

HR maintains the Code of Conduct, answers questions about it and reports on its use to the management team.
