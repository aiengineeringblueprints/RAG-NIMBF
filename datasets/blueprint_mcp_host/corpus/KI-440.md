# Project Brief PRJ-240: Summit Leak Detection Rollout

Kestrel Instruments. Internal use only.

## Introduction

Rosen Pharma ApS commissioned project PRJ-240 (Summit Leak Detection Rollout).

Project PRJ-240 replaces manual readings with continuous monitoring, so that Rosen Pharma ApS can react to deviations faster.

The goal of project PRJ-240 is to improve data quality and reduce maintenance effort for Rosen Pharma ApS.

Rosen Pharma ApS commissioned project PRJ-240 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

## Key information

- Project code: PRJ-240
- Customer: Rosen Pharma ApS
- Project lead: Karin Solberg
- Delivery site: Oslo
- Product: Kestrel KQ2
- Start date: 2025-05-10
- Final deadline: 2026-01-17

The project is led by Karin Solberg and run from the Oslo site. The solution is based on the Kestrel KQ2.

## Budget

The initial estimate was 896500 EUR. After the scope review the steering committee approved a budget of 889000 EUR.

## Communication plan

Decisions in project PRJ-240 are documented in the decision log and confirmed by email.

Weekly calls between the project teams of Rosen Pharma ApS and Kestrel keep project PRJ-240 on track between steering committee meetings.

Project PRJ-240 uses a shared workspace for documents, meeting minutes and open points.

## Scope of delivery

Civil works and cabling outside the measuring points are not part of project PRJ-240 and are provided by Rosen Pharma ApS.

The scope of project PRJ-240 covers delivery, installation and commissioning of Kestrel KQ2 devices and their integration into the customer's control system.

Project PRJ-240 includes training for the customer's maintenance staff and a documentation package for audits.

Optional services in project PRJ-240, such as extended support, are offered separately.

## Risk register

| Risk | Mitigation |
|---|---|
| Weather conditions for outdoor work | Schedule outdoor installation with buffer time |
| Scope changes | Handle changes through the standard change process |
| Interfaces to legacy systems | Run an interface test in the first project phase |
| Supply bottlenecks for components | Order critical parts at project start |
| Delayed site access | Agree access windows early with the customer |

## Goals

- Replace legacy instruments with current Kestrel devices
- Reduce manual inspection rounds
- Hand over a validated configuration backup
- Train the customer's technicians
- Provide remote diagnostics for the service team
