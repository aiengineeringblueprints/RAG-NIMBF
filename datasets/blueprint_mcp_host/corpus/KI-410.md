# Project Brief PRJ-210: Arctic Automation Retrofit

Kestrel Instruments. Internal use only.

## Introduction

Fjellheim Data Oy commissioned project PRJ-210 (Arctic Automation Retrofit).

The goal of project PRJ-210 is to improve data quality and reduce maintenance effort for Fjellheim Data Oy.

Project PRJ-210 replaces manual readings with continuous monitoring, so that Fjellheim Data Oy can react to deviations faster.

Fjellheim Data Oy commissioned project PRJ-210 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

## Scope

Civil works and cabling outside the measuring points are not part of project PRJ-210 and are provided by Fjellheim Data Oy.

The scope of project PRJ-210 covers delivery, installation and commissioning of Kestrel KD1 devices and their integration into the customer's control system.

Optional services in project PRJ-210, such as extended support, are offered separately.

Project PRJ-210 includes training for the customer's maintenance staff and a documentation package for audits.

Live figures of project PRJ-210 such as budget spent and percent complete are tracked in the project system, not in this brief.

## Objectives

- Integrate all measuring points into the customer's control system
- Reduce manual inspection rounds
- Provide remote diagnostics for the service team
- Replace legacy instruments with current Kestrel devices
- Document the installation for later audits
- Train the customer's technicians
