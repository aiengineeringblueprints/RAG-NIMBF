## Root cause

The root cause was a firmware memory leak.

## Contributing factors

- The fault was first mistaken for a network problem
- Documentation of the installation was incomplete

## Corrective actions

| Action | Owner | Status |
|---|---|---|
| Ship the fix with firmware 2.8.2 | Engineering | done |
| Review spare part stock for key customers | Logistics | open |
| Update the installation checklist | Quality | done |
| Share lessons learned in the engineering forum | Engineering | in progress |
| Roll out the fix to all affected installations | Engineering | open |

The fix shipped with firmware 2.8.2.

## Lessons learned

- Checklists need regular review after incidents
- Early escalation shortened the investigation

Similar installations at other customers were checked for the conditions that led to incident INC-2026-049.
