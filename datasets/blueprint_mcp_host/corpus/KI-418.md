# Project Brief PRJ-218: Aurora Climate Control Rollout

Kestrel Instruments. Internal use only.

## Introduction

Ahlberg Data AS commissioned project PRJ-218 (Aurora Climate Control Rollout).

Project PRJ-218 replaces manual readings with continuous monitoring, so that Ahlberg Data AS can react to deviations faster.

The goal of project PRJ-218 is to improve data quality and reduce maintenance effort for Ahlberg Data AS.

## Project facts

- Project code: PRJ-218
- Customer: Ahlberg Data AS
- Project lead: Sindre Jensen
- Delivery site: Stavanger
- Product: Kestrel KW7
- Start date: 2026-05-12
- Final deadline: 2027-05-01

The project is led by Sindre Jensen and run from the Stavanger site. The solution is based on the Kestrel KW7.

## Financials

The initial estimate was 261000 EUR. After the scope review the steering committee approved a budget of 283000 EUR.

## Scope

Project PRJ-218 includes training for the customer's maintenance staff and a documentation package for audits.

The scope of project PRJ-218 covers delivery, installation and commissioning of Kestrel KW7 devices and their integration into the customer's control system.
