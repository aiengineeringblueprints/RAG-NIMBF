# Kestrel KL2-L Discontinuation Notice

Owner: Kestrel Instruments. Classification: internal.

The Kestrel KL2-L, predecessor of the Kestrel KL2, was discontinued in 2021. The KL2-L had a maximum operating temperature of 90 °C. It used SKU KS-0903 and is no longer stocked.

## Migration

Customers still operating a KL2-L should plan the migration to the Kestrel KL2. The successor uses the same mounting dimensions, but wiring and configuration must be checked against its current datasheet before replacement.

- Check the current datasheet of the successor
- Order mounting adapters if needed
- Back up the existing configuration
- Plan the replacement in a maintenance window
