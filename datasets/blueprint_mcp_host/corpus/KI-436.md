# Project Brief PRJ-236: Aurora Diagnostics Retrofit

Kestrel Instruments, internal document.

## Introduction

Kvist Bygg AB commissioned project PRJ-236 (Aurora Diagnostics Retrofit).

Project PRJ-236 replaces manual readings with continuous monitoring, so that Kvist Bygg AB can react to deviations faster.

The goal of project PRJ-236 is to improve data quality and reduce maintenance effort for Kvist Bygg AB.

Kvist Bygg AB commissioned project PRJ-236 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

## Scope

The scope of project PRJ-236 covers delivery, installation and commissioning of Kestrel KV5 devices and their integration into the customer's control system.

Project PRJ-236 includes training for the customer's maintenance staff and a documentation package for audits.

Optional services in project PRJ-236, such as extended support, are offered separately.

Civil works and cabling outside the measuring points are not part of project PRJ-236 and are provided by Kvist Bygg AB.

## Objectives

- Integrate all measuring points into the customer's control system
- Hand over a validated configuration backup
- Provide remote diagnostics for the service team
- Replace legacy instruments with current Kestrel devices
- Reduce manual inspection rounds
