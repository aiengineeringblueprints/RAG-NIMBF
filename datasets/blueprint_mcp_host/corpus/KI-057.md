# KL Series Firmware Release Notes (level sensors)

Kestrel Instruments. Internal use only.

## About these release notes

Firmware for the KL series is cumulative: every release contains all fixes of the earlier releases. Downgrades are possible but not recommended.

These release notes list the firmware history of the KL series. Install the latest release unless a project specification requires a validated older version.

## Compatibility notes

Configuration backups created with older KL firmware can be restored on newer releases; the reverse direction is not supported.

All releases of the KL series work with the current Kestrel Configurator. Older configurator versions can read but not write settings of the latest firmware.

Firmware releases of the KL series keep the communication register map stable, so control system integrations do not need changes after an update.

## Installing updates

If an update of a KL device fails, the previous image stays active and the update can be repeated. Roll back through the service portal if necessary.

Devices of the KL series keep their configuration during an update. Create a configuration backup anyway before updating devices in the field.

Download the firmware image for the KL series from the Kestrel service portal and verify the signature before distributing it.

Plan updates of KL devices for maintenance windows, because measurements are interrupted while the new image is activated.
