# Project Brief PRJ-238: Glacier Metering Upgrade

Owner: Kestrel Instruments. Classification: internal.

## Background

Project PRJ-238, Glacier Metering Upgrade, is delivered for Fjellheim Data Oy.

Project PRJ-238 replaces manual readings with continuous monitoring, so that Fjellheim Data Oy can react to deviations faster.

Fjellheim Data Oy commissioned project PRJ-238 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.
