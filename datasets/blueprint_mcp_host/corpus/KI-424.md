# Project Brief PRJ-224: Coastal Metering Expansion

Owner: Kestrel Instruments. Classification: internal.

## Context

Project PRJ-224, Coastal Metering Expansion, is delivered for Holmen Kraft Oy.

The goal of project PRJ-224 is to improve data quality and reduce maintenance effort for Holmen Kraft Oy.

Project PRJ-224 replaces manual readings with continuous monitoring, so that Holmen Kraft Oy can react to deviations faster.

Holmen Kraft Oy commissioned project PRJ-224 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

## Key information

Project code: PRJ-224. Customer: Holmen Kraft Oy. Project lead: Magnus Aune. Delivery site: Gothenburg. Product: Kestrel KQ4. Start date: 2026-01-16. Final deadline: 2026-05-25.

The project is led by Magnus Aune and run from the Gothenburg site. The solution is based on the Kestrel KQ4.

## Financials

The initial estimate was 817000 EUR. After the scope review the steering committee approved a budget of 794500 EUR.

## Scope

Project PRJ-224 includes training for the customer's maintenance staff and a documentation package for audits.

Civil works and cabling outside the measuring points are not part of project PRJ-224 and are provided by Holmen Kraft Oy.

The scope of project PRJ-224 covers delivery, installation and commissioning of Kestrel KQ4 devices and their integration into the customer's control system.

Optional services in project PRJ-224, such as extended support, are offered separately.

## Goals

- Provide remote diagnostics for the service team
- Integrate all measuring points into the customer's control system
- Replace legacy instruments with current Kestrel devices
- Train the customer's technicians
- Hand over a validated configuration backup
- Reduce manual inspection rounds
