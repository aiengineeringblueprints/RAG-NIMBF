# KG Series Firmware Release Notes (gas sensors)

Owner: Kestrel Instruments. Classification: internal.

## Scope of this document

The KG series shares one firmware code base, but each model receives its own signed image. Images cannot be exchanged between models.

These release notes list the firmware history of the KG series. Install the latest release unless a project specification requires a validated older version.

## Security

Releases of the KG series are signed, and devices reject images with an invalid signature. Report suspected vulnerabilities to the Kestrel product security team.

Kestrel recommends restricting network access to KG devices to the control network and changing default user codes during commissioning.

Security fixes for the KG series are announced through the service portal and the customer newsletter.

## Known issues

- Remote configuration backups fail on networks with very high latency.
- The event list is cleared after a factory reset.

## Compatibility notes

All releases of the KG series work with the current Kestrel Configurator. Older configurator versions can read but not write settings of the latest firmware.

Firmware releases of the KG series keep the communication register map stable, so control system integrations do not need changes after an update.

## How to update

Download the firmware image for the KG series from the Kestrel service portal and verify the signature before distributing it.

Plan updates of KG devices for maintenance windows, because measurements are interrupted while the new image is activated.
