# KP Series Firmware Release Notes (pressure transmitters)

Owner: Kestrel Instruments. Classification: internal.

## About these release notes

The KP series shares one firmware code base, but each model receives its own signed image. Images cannot be exchanged between models.

Firmware for the KP series is cumulative: every release contains all fixes of the earlier releases. Downgrades are possible but not recommended.

These release notes list the firmware history of the KP series. Install the latest release unless a project specification requires a validated older version.

## Security information

Security fixes for the KP series are announced through the service portal and the customer newsletter.

Kestrel recommends restricting network access to KP devices to the control network and changing default user codes during commissioning.

Releases of the KP series are signed, and devices reject images with an invalid signature. Report suspected vulnerabilities to the Kestrel product security team.

## Known issues

- Some diagnostic texts are only available in English.
- Remote configuration backups fail on networks with very high latency.

## Compatibility notes

Firmware releases of the KP series keep the communication register map stable, so control system integrations do not need changes after an update.

## Update procedure

If an update of a KP device fails, the previous image stays active and the update can be repeated. Roll back through the service portal if necessary.

Devices of the KP series keep their configuration during an update. Create a configuration backup anyway before updating devices in the field.

Download the firmware image for the KP series from the Kestrel service portal and verify the signature before distributing it.

Plan updates of KP devices for maintenance windows, because measurements are interrupted while the new image is activated.
