# Project Brief PRJ-234: Pine Metering Pilot

Owner: Kestrel Instruments. Classification: internal.

## Introduction

Project PRJ-234, Pine Metering Pilot, is delivered for Kvist Bygg AB.

Project PRJ-234 replaces manual readings with continuous monitoring, so that Kvist Bygg AB can react to deviations faster.

The goal of project PRJ-234 is to improve data quality and reduce maintenance effort for Kvist Bygg AB.

Kvist Bygg AB commissioned project PRJ-234 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

## Key information

Project code: PRJ-234. Customer: Kvist Bygg AB. Project lead: Paul Hedlund. Delivery site: Stavanger. Product: Kestrel KT4. Start date: 2026-03-27. Final deadline: 2027-07-17.

The project is led by Paul Hedlund and run from the Stavanger site. The solution is based on the Kestrel KT4.

## Scope of delivery

Optional services in project PRJ-234, such as extended support, are offered separately.

Civil works and cabling outside the measuring points are not part of project PRJ-234 and are provided by Kvist Bygg AB.

The scope of project PRJ-234 covers delivery, installation and commissioning of Kestrel KT4 devices and their integration into the customer's control system.

Project PRJ-234 includes training for the customer's maintenance staff and a documentation package for audits.

## Objectives

- Hand over a validated configuration backup
- Integrate all measuring points into the customer's control system
- Reduce manual inspection rounds
- Train the customer's technicians
- Provide remote diagnostics for the service team
- Replace legacy instruments with current Kestrel devices
