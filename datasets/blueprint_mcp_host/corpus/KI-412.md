# Project Brief PRJ-212: Northern Metering Pilot

Owner: Kestrel Instruments. Classification: internal.

## Context

Project PRJ-212, Northern Metering Pilot, is delivered for Granlund Data Inc.

The goal of project PRJ-212 is to improve data quality and reduce maintenance effort for Granlund Data Inc.

Granlund Data Inc. commissioned project PRJ-212 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

Project PRJ-212 replaces manual readings with continuous monitoring, so that Granlund Data Inc. can react to deviations faster.

## Scope of delivery

The scope of project PRJ-212 covers delivery, installation and commissioning of Kestrel KP9 devices and their integration into the customer's control system.

Civil works and cabling outside the measuring points are not part of project PRJ-212 and are provided by Granlund Data Inc.

Project PRJ-212 includes training for the customer's maintenance staff and a documentation package for audits.

Optional services in project PRJ-212, such as extended support, are offered separately.
