# KF Series Firmware Release Notes (flow meters)

Kestrel Instruments. Internal use only.

## Introduction

Firmware for the KF series is cumulative: every release contains all fixes of the earlier releases. Downgrades are possible but not recommended.

The KF series shares one firmware code base, but each model receives its own signed image. Images cannot be exchanged between models.

## Known limitations

- Some diagnostic texts are only available in English.
- The status LED can flash briefly during the self-test after an update.
- Older configurator versions show the firmware date in the wrong time zone.
- The event list is cleared after a factory reset.
