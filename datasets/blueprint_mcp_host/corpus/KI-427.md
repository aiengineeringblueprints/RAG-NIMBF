# Project Brief PRJ-227: Glacier Leak Detection Rollout

Kestrel Instruments. Internal use only.

## Context

Haugland Logistics ApS commissioned project PRJ-227 (Glacier Leak Detection Rollout).

Project PRJ-227 replaces manual readings with continuous monitoring, so that Haugland Logistics ApS can react to deviations faster.

The goal of project PRJ-227 is to improve data quality and reduce maintenance effort for Haugland Logistics ApS.
