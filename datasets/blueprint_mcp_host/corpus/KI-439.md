# Project Brief PRJ-239: Fjord Climate Control Upgrade

Kestrel Instruments, internal document.

## Introduction

Holmen Kraft Oy commissioned project PRJ-239 (Fjord Climate Control Upgrade).

Project PRJ-239 replaces manual readings with continuous monitoring, so that Holmen Kraft Oy can react to deviations faster.

The goal of project PRJ-239 is to improve data quality and reduce maintenance effort for Holmen Kraft Oy.

Holmen Kraft Oy commissioned project PRJ-239 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

## Project facts

- Project code: PRJ-239
- Customer: Holmen Kraft Oy
- Project lead: Lars Brandt
- Delivery site: Oslo
- Product: Kestrel KG7
- Start date: 2025-06-18
- Final deadline: 2025-11-16

The project is led by Lars Brandt and run from the Oslo site. The solution is based on the Kestrel KG7.

## Budget

The initial estimate was 786500 EUR. After the scope review the steering committee approved a budget of 760500 EUR.

## Scope

Optional services in project PRJ-239, such as extended support, are offered separately.

Project PRJ-239 includes training for the customer's maintenance staff and a documentation package for audits.

Civil works and cabling outside the measuring points are not part of project PRJ-239 and are provided by Holmen Kraft Oy.

The scope of project PRJ-239 covers delivery, installation and commissioning of Kestrel KG7 devices and their integration into the customer's control system.

## Project organisation

A steering committee with representatives of Holmen Kraft Oy and Kestrel meets at every milestone of project PRJ-239.

Status reports are shared with Holmen Kraft Oy every two weeks. Change requests follow the standard change process and need written approval.

Live figures of project PRJ-239 such as budget spent and percent complete are tracked in the project system, not in this brief.

## Kickoff meeting minutes

- Interfaces to the control system were discussed
- Open questions were assigned to owners
- Roles and responsibilities were confirmed
- The customer presented site access rules
- Reporting format and frequency were agreed

## Communication

Decisions in project PRJ-239 are documented in the decision log and confirmed by email.

Project PRJ-239 uses a shared workspace for documents, meeting minutes and open points.

Weekly calls between the project teams of Holmen Kraft Oy and Kestrel keep project PRJ-239 on track between steering committee meetings.

## Risk register

| Risk | Mitigation |
|---|---|
| Interfaces to legacy systems | Run an interface test in the first project phase |
| Supply bottlenecks for components | Order critical parts at project start |
| Weather conditions for outdoor work | Schedule outdoor installation with buffer time |

## Goals

- Reduce manual inspection rounds
- Document the installation for later audits
- Train the customer's technicians
- Integrate all measuring points into the customer's control system
- Replace legacy instruments with current Kestrel devices
- Hand over a validated configuration backup
