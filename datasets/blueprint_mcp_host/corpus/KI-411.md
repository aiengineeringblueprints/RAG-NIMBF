# Project Brief PRJ-211: Aurora Metering Rollout

Owner: Kestrel Instruments. Classification: internal.

## Context

Ahlberg Marine Oy commissioned project PRJ-211 (Aurora Metering Rollout).

The goal of project PRJ-211 is to improve data quality and reduce maintenance effort for Ahlberg Marine Oy.

Ahlberg Marine Oy commissioned project PRJ-211 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

Project PRJ-211 replaces manual readings with continuous monitoring, so that Ahlberg Marine Oy can react to deviations faster.

## Key information

Project code: PRJ-211. Customer: Ahlberg Marine Oy. Project lead: Lena Kvam. Delivery site: Trondheim. Product: Kestrel KP5. Start date: 2025-09-11. Final deadline: 2027-07-20.

The project is led by Lena Kvam and run from the Trondheim site. The solution is based on the Kestrel KP5.

## Scope of delivery

Civil works and cabling outside the measuring points are not part of project PRJ-211 and are provided by Ahlberg Marine Oy.

Project PRJ-211 includes training for the customer's maintenance staff and a documentation package for audits.

The scope of project PRJ-211 covers delivery, installation and commissioning of Kestrel KP5 devices and their integration into the customer's control system.

Optional services in project PRJ-211, such as extended support, are offered separately.

## Objectives

- Replace legacy instruments with current Kestrel devices
- Integrate all measuring points into the customer's control system
- Reduce manual inspection rounds
- Provide remote diagnostics for the service team
