# Project Brief PRJ-220: Tidal Telemetry Expansion

Kestrel Instruments, internal document.

## Introduction

Project PRJ-220, Tidal Telemetry Expansion, is delivered for Halland Energi AS.

Halland Energi AS commissioned project PRJ-220 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

The goal of project PRJ-220 is to improve data quality and reduce maintenance effort for Halland Energi AS.

Project PRJ-220 replaces manual readings with continuous monitoring, so that Halland Energi AS can react to deviations faster.

## Key information

Project code: PRJ-220. Customer: Halland Energi AS. Project lead: Lena Kvam. Delivery site: Trondheim. Product: Kestrel KH3. Start date: 2025-04-14. Final deadline: 2026-01-08.

The project is led by Lena Kvam and run from the Trondheim site. The solution is based on the Kestrel KH3.

## Budget

The initial estimate was 817500 EUR. After the scope review the steering committee approved a budget of 804500 EUR.

## Scope of delivery

The scope of project PRJ-220 covers delivery, installation and commissioning of Kestrel KH3 devices and their integration into the customer's control system.

Civil works and cabling outside the measuring points are not part of project PRJ-220 and are provided by Halland Energi AS.

Optional services in project PRJ-220, such as extended support, are offered separately.

Project PRJ-220 includes training for the customer's maintenance staff and a documentation package for audits.

## Objectives

- Replace legacy instruments with current Kestrel devices
- Hand over a validated configuration backup
- Reduce manual inspection rounds
- Document the installation for later audits
