# Project Brief PRJ-215: Coastal Monitoring Upgrade

Kestrel Instruments. Internal use only.

## Background

Project PRJ-215, Coastal Monitoring Upgrade, is delivered for Rosen Pharma ApS.

Project PRJ-215 replaces manual readings with continuous monitoring, so that Rosen Pharma ApS can react to deviations faster.

Rosen Pharma ApS commissioned project PRJ-215 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

The goal of project PRJ-215 is to improve data quality and reduce maintenance effort for Rosen Pharma ApS.

## Scope of delivery

Optional services in project PRJ-215, such as extended support, are offered separately.

Civil works and cabling outside the measuring points are not part of project PRJ-215 and are provided by Rosen Pharma ApS.

Project PRJ-215 includes training for the customer's maintenance staff and a documentation package for audits.

The scope of project PRJ-215 covers delivery, installation and commissioning of Kestrel KL2 devices and their integration into the customer's control system.

## Communication

Weekly calls between the project teams of Rosen Pharma ApS and Kestrel keep project PRJ-215 on track between steering committee meetings.

Decisions in project PRJ-215 are documented in the decision log and confirmed by email.

Project PRJ-215 uses a shared workspace for documents, meeting minutes and open points.

## Governance

A steering committee with representatives of Rosen Pharma ApS and Kestrel meets at every milestone of project PRJ-215.

Status reports are shared with Rosen Pharma ApS every two weeks. Change requests follow the standard change process and need written approval.

Live figures of project PRJ-215 such as budget spent and percent complete are tracked in the project system, not in this brief.

## Risks

| Risk | Mitigation |
|---|---|
| Staff availability during holidays | Plan deputies for all key roles |
| Weather conditions for outdoor work | Schedule outdoor installation with buffer time |
| Interfaces to legacy systems | Run an interface test in the first project phase |
