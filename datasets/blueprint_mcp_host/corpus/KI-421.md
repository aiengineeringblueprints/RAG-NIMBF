# Project Brief PRJ-221: Arctic Telemetry Pilot

Owner: Kestrel Instruments. Classification: internal.

## Context

Haugland Logistics ApS commissioned project PRJ-221 (Arctic Telemetry Pilot).

The goal of project PRJ-221 is to improve data quality and reduce maintenance effort for Haugland Logistics ApS.

Project PRJ-221 replaces manual readings with continuous monitoring, so that Haugland Logistics ApS can react to deviations faster.

Haugland Logistics ApS commissioned project PRJ-221 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

## Objectives

- Replace legacy instruments with current Kestrel devices
- Train the customer's technicians

## Scope

Civil works and cabling outside the measuring points are not part of project PRJ-221 and are provided by Haugland Logistics ApS.

Project PRJ-221 includes training for the customer's maintenance staff and a documentation package for audits.

The scope of project PRJ-221 covers delivery, installation and commissioning of Kestrel KV4 devices and their integration into the customer's control system.

Optional services in project PRJ-221, such as extended support, are offered separately.
