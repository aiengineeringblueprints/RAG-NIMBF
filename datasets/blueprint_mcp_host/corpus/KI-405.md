# Project Brief PRJ-205: Glacier Diagnostics Retrofit

Kestrel Instruments, internal document.

## Background

Project PRJ-205, Glacier Diagnostics Retrofit, is delivered for Ahlberg Data AS.

Ahlberg Data AS commissioned project PRJ-205 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

The goal of project PRJ-205 is to improve data quality and reduce maintenance effort for Ahlberg Data AS.

Project PRJ-205 replaces manual readings with continuous monitoring, so that Ahlberg Data AS can react to deviations faster.

## Project data

Project code: PRJ-205. Customer: Ahlberg Data AS. Project lead: Helga Sandvik. Delivery site: Trondheim. Product: Kestrel KV9. Start date: 2025-04-27. Final deadline: 2026-01-29.

The project is led by Helga Sandvik and run from the Trondheim site. The solution is based on the Kestrel KV9.

## Scope of delivery

Project PRJ-205 includes training for the customer's maintenance staff and a documentation package for audits.

Civil works and cabling outside the measuring points are not part of project PRJ-205 and are provided by Ahlberg Data AS.

Optional services in project PRJ-205, such as extended support, are offered separately.

The scope of project PRJ-205 covers delivery, installation and commissioning of Kestrel KV9 devices and their integration into the customer's control system.

## Objectives

- Hand over a validated configuration backup
- Train the customer's technicians
- Replace legacy instruments with current Kestrel devices
