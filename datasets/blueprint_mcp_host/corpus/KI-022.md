# Kestrel KV4 Datasheet

Kestrel Instruments. Internal use only.

## Overview

Product overview: the Kestrel KV4 (vibration sensor) is ordered with SKU KS-1022 and has been on the market since it was launched in 2021.

Every Kestrel KV4 leaves the factory with an individual test report. The report documents the final functional test and the configuration loaded before shipment, which simplifies acceptance testing on site.

## Technical data

| Item | Value |
|---|---|
| Minimum operating temperature | -30 °C |
| Maximum operating temperature | 80 °C |
| Supply current | 29 mA |
| Communication interface | EtherNet/IP |
| Accuracy | ±5 % of range |
| Enclosure rating | IP40 |
| Weight (current revision) | 895 g |

The Kestrel KV4 operates between -30 °C and 80 °C and communicates via EtherNet/IP.

## Compliance

Test reports for the Kestrel KV4 are kept for the whole support period and can be provided for customer audits.

## Mechanical installation

The Kestrel KV4 can be mounted on a wall bracket, a pipe clamp or a standard mounting rail. Choose the mounting kit that matches the installation and tighten the screws evenly.

## Electrical connection

Install a suitable fuse in the supply line of the Kestrel KV4 and protect the signal lines against surges where long cable runs leave the building.

## Maintenance

Recalibrate the Kestrel KV4 according to the calibration procedure of Kestrel Instruments or send it to an accredited calibration lab.
