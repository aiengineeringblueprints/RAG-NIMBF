# Kestrel KW7-L Discontinuation Notice

Kestrel Instruments. Internal use only.

The Kestrel KW7-L, predecessor of the Kestrel KW7, was discontinued in 2019. The KW7-L had a maximum operating temperature of 65 °C. It used SKU KS-0901 and is no longer stocked.

## Migration

Customers still operating a KW7-L should plan the migration to the Kestrel KW7. The successor uses the same mounting dimensions, but wiring and configuration must be checked against its current datasheet before replacement.

- Check the current datasheet of the successor
- Order mounting adapters if needed
- Back up the existing configuration
- Plan the replacement in a maintenance window
