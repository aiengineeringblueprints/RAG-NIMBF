# Project Brief PRJ-235: Tidal Telemetry Upgrade

Kestrel Instruments. Internal use only.

## Context

Lundby Bygg Inc. commissioned project PRJ-235 (Tidal Telemetry Upgrade).

Project PRJ-235 replaces manual readings with continuous monitoring, so that Lundby Bygg Inc. can react to deviations faster.

The goal of project PRJ-235 is to improve data quality and reduce maintenance effort for Lundby Bygg Inc.

## Financials

The initial estimate was 130000 EUR. After the scope review the steering committee approved a budget of 155500 EUR.

## Governance

A steering committee with representatives of Lundby Bygg Inc. and Kestrel meets at every milestone of project PRJ-235.

Live figures of project PRJ-235 such as budget spent and percent complete are tracked in the project system, not in this brief.

## Scope

Project PRJ-235 includes training for the customer's maintenance staff and a documentation package for audits.

The scope of project PRJ-235 covers delivery, installation and commissioning of Kestrel KG9 devices and their integration into the customer's control system.

Optional services in project PRJ-235, such as extended support, are offered separately.
