# Project Brief PRJ-225: Delta Climate Control Upgrade

Kestrel Instruments, internal document.

## Introduction

Vikholm Marine Inc. commissioned project PRJ-225 (Delta Climate Control Upgrade).

The goal of project PRJ-225 is to improve data quality and reduce maintenance effort for Vikholm Marine Inc.

Project PRJ-225 replaces manual readings with continuous monitoring, so that Vikholm Marine Inc. can react to deviations faster.

Live figures of project PRJ-225 such as budget spent and percent complete are tracked in the project system, not in this brief.

## Communication plan

Project PRJ-225 uses a shared workspace for documents, meeting minutes and open points.
