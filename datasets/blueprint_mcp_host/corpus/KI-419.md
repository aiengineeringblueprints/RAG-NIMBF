# Project Brief PRJ-219: Fjord Telemetry Rollout

Kestrel Instruments. Internal use only.

## Introduction

Project PRJ-219, Fjord Telemetry Rollout, is delivered for Kolbu Mining AS.

The goal of project PRJ-219 is to improve data quality and reduce maintenance effort for Kolbu Mining AS.

Project PRJ-219 replaces manual readings with continuous monitoring, so that Kolbu Mining AS can react to deviations faster.

## Project data

Project code: PRJ-219. Customer: Kolbu Mining AS. Project lead: Eirik Wallin. Delivery site: Hamburg. Product: Kestrel KW8. Start date: 2025-11-03. Final deadline: 2027-08-21.

The project is led by Eirik Wallin and run from the Hamburg site. The solution is based on the Kestrel KW8.

## Budget

The initial estimate was 752500 EUR. After the scope review the steering committee approved a budget of 744000 EUR.

| Risk | Mitigation |

| Interfaces to legacy systems | Run an interface test in the first project phase |
| Weather conditions for outdoor work | Schedule outdoor installation with buffer time |

Status reports are shared with Kolbu Mining AS every two weeks. Change requests follow the standard change process and need written approval.
