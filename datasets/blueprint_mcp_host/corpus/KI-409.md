# Project Brief PRJ-209: Coastal Monitoring Retrofit

Kestrel Instruments, internal document.

## Context

Nessby Kraft GmbH commissioned project PRJ-209 (Coastal Monitoring Retrofit).

Project PRJ-209 replaces manual readings with continuous monitoring, so that Nessby Kraft GmbH can react to deviations faster.

Nessby Kraft GmbH commissioned project PRJ-209 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

The goal of project PRJ-209 is to improve data quality and reduce maintenance effort for Nessby Kraft GmbH.

## Objectives

- Document the installation for later audits
- Integrate all measuring points into the customer's control system
- Train the customer's technicians
- Reduce manual inspection rounds

## Scope

The scope of project PRJ-209 covers delivery, installation and commissioning of Kestrel KD1 devices and their integration into the customer's control system.

Project PRJ-209 includes training for the customer's maintenance staff and a documentation package for audits.

Optional services in project PRJ-209, such as extended support, are offered separately.

Civil works and cabling outside the measuring points are not part of project PRJ-209 and are provided by Nessby Kraft GmbH.
