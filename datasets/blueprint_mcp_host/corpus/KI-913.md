# Kestrel KL3-L Discontinuation Notice

Owner: Kestrel Instruments. Classification: internal.

The Kestrel KL3-L, predecessor of the Kestrel KL3, was discontinued in 2020. The KL3-L had a maximum operating temperature of 110 °C. It used SKU KS-0902 and is no longer stocked.

## Migration

Customers still operating a KL3-L should plan the migration to the Kestrel KL3. The successor uses the same mounting dimensions, but wiring and configuration must be checked against its current datasheet before replacement.

- Check the current datasheet of the successor
- Order mounting adapters if needed
- Back up the existing configuration
- Plan the replacement in a maintenance window
