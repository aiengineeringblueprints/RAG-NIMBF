# Project Brief PRJ-226: Harbor Monitoring Rollout

Kestrel Instruments, internal document.

## Background

Project PRJ-226, Harbor Monitoring Rollout, is delivered for Dalsbo Marine AB.

Dalsbo Marine AB commissioned project PRJ-226 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

The goal of project PRJ-226 is to improve data quality and reduce maintenance effort for Dalsbo Marine AB.

Project PRJ-226 replaces manual readings with continuous monitoring, so that Dalsbo Marine AB can react to deviations faster.

## Key information

Project code: PRJ-226. Customer: Dalsbo Marine AB. Project lead: Paul Hedlund. Delivery site: Stavanger. Product: Kestrel KF2. Start date: 2025-07-21. Final deadline: 2026-05-05.

The project is led by Paul Hedlund and run from the Stavanger site. The solution is based on the Kestrel KF2.

## Scope

Project PRJ-226 includes training for the customer's maintenance staff and a documentation package for audits.

Civil works and cabling outside the measuring points are not part of project PRJ-226 and are provided by Dalsbo Marine AB.

The scope of project PRJ-226 covers delivery, installation and commissioning of Kestrel KF2 devices and their integration into the customer's control system.

Optional services in project PRJ-226, such as extended support, are offered separately.
