# Incident Report INC-2026-289

Owner: Kestrel Instruments. Classification: internal.

## Summary

Incident INC-2026-289 interrupted measurements at Hedberg Aqua GmbH and was handled by customer support together with engineering.

Incident INC-2026-289 occurred on 30 November 2025 at Hedberg Aqua GmbH. The affected product was the Kestrel KF2 and the incident was classified as severity 3.

## Root cause analysis

The root cause was lightning damage to the field wiring.

## Other factors

- Monitoring did not alert on the first symptoms
- Documentation of the installation was incomplete
- Spare devices were not available on site
- The affected installation was not on the latest firmware

## Actions

| Action | Owner | Status |
|---|---|---|
| Ship the fix with firmware 1.6.4 | Engineering | done |
| Review spare part stock for key customers | Logistics | done |
| Add an alert for the observed symptom | Customer Support | in progress |
| Update the installation checklist | Quality | done |
| Roll out the fix to all affected installations | Engineering | open |

The fix shipped with firmware 1.6.4.

## Lessons learned

- Early escalation shortened the investigation
- Clear customer communication reduced pressure on the team
- Checklists need regular review after incidents
- Remote diagnostics access was essential

## Next steps

The knowledge base was updated with the diagnosis steps used during incident INC-2026-289.
