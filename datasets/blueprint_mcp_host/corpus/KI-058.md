# KD Series Firmware Release Notes (data loggers)

Owner: Kestrel Instruments. Classification: internal.

## About these release notes

The KD series shares one firmware code base, but each model receives its own signed image. Images cannot be exchanged between models.

These release notes list the firmware history of the KD series. Install the latest release unless a project specification requires a validated older version.

Firmware for the KD series is cumulative: every release contains all fixes of the earlier releases. Downgrades are possible but not recommended.

## Installing updates

If an update of a KD device fails, the previous image stays active and the update can be repeated. Roll back through the service portal if necessary.

Plan updates of KD devices for maintenance windows, because measurements are interrupted while the new image is activated.

Devices of the KD series keep their configuration during an update. Create a configuration backup anyway before updating devices in the field.

Download the firmware image for the KD series from the Kestrel service portal and verify the signature before distributing it.

## Security information

Security fixes for the KD series are announced through the service portal and the customer newsletter.

Releases of the KD series are signed, and devices reject images with an invalid signature. Report suspected vulnerabilities to the Kestrel product security team.

Kestrel recommends restricting network access to KD devices to the control network and changing default user codes during commissioning.

## Known limitations

- Some diagnostic texts are only available in English.
- The status LED can flash briefly during the self-test after an update.
- Older configurator versions show the firmware date in the wrong time zone.
- Remote configuration backups fail on networks with very high latency.
- The event list is cleared after a factory reset.

## Compatibility notes

All releases of the KD series work with the current Kestrel Configurator. Older configurator versions can read but not write settings of the latest firmware.

Firmware releases of the KD series keep the communication register map stable, so control system integrations do not need changes after an update.

Configuration backups created with older KD firmware can be restored on newer releases; the reverse direction is not supported.
