# Project Brief PRJ-214: Delta Climate Control Retrofit

Kestrel Instruments. Internal use only.

## Introduction

Project PRJ-214, Delta Climate Control Retrofit, is delivered for Nordvik Mining Inc.

The goal of project PRJ-214 is to improve data quality and reduce maintenance effort for Nordvik Mining Inc.

Project PRJ-214 replaces manual readings with continuous monitoring, so that Nordvik Mining Inc. can react to deviations faster.

Nordvik Mining Inc. commissioned project PRJ-214 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

## Project facts

- Project code: PRJ-214
- Customer: Nordvik Mining Inc.
- Project lead: Petter Brekke
- Delivery site: Oslo
- Product: Kestrel KH5
- Start date: 2026-03-30
- Final deadline: 2026-09-01

The project is led by Petter Brekke and run from the Oslo site. The solution is based on the Kestrel KH5.

## Budget

The initial estimate was 293000 EUR. After the scope review the steering committee approved a budget of 280000 EUR.

## Objectives

- Reduce manual inspection rounds
- Train the customer's technicians
- Replace legacy instruments with current Kestrel devices

## Scope of delivery

The scope of project PRJ-214 covers delivery, installation and commissioning of Kestrel KH5 devices and their integration into the customer's control system.

Civil works and cabling outside the measuring points are not part of project PRJ-214 and are provided by Nordvik Mining Inc.

Optional services in project PRJ-214, such as extended support, are offered separately.

Project PRJ-214 includes training for the customer's maintenance staff and a documentation package for audits.
