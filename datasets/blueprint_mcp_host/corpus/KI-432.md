# Project Brief PRJ-232: Coastal Metering Upgrade

Owner: Kestrel Instruments. Classification: internal.

## Background

Kolbu Aqua AS commissioned project PRJ-232 (Coastal Metering Upgrade).

Project PRJ-232 replaces manual readings with continuous monitoring, so that Kolbu Aqua AS can react to deviations faster.

The goal of project PRJ-232 is to improve data quality and reduce maintenance effort for Kolbu Aqua AS.
