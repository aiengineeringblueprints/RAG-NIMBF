# KW Series Firmware Release Notes (wireless gateways)

Kestrel Instruments. Internal use only.

## Scope of this document

Firmware for the KW series is cumulative: every release contains all fixes of the earlier releases. Downgrades are possible but not recommended.

These release notes list the firmware history of the KW series. Install the latest release unless a project specification requires a validated older version.

The KW series shares one firmware code base, but each model receives its own signed image. Images cannot be exchanged between models.

## Known limitations

- Some diagnostic texts are only available in English.
- The event list is cleared after a factory reset.
- Older configurator versions show the firmware date in the wrong time zone.
- Readings may pause briefly after a configuration import.

## Compatibility

Configuration backups created with older KW firmware can be restored on newer releases; the reverse direction is not supported.

Firmware releases of the KW series keep the communication register map stable, so control system integrations do not need changes after an update.

All releases of the KW series work with the current Kestrel Configurator. Older configurator versions can read but not write settings of the latest firmware.

## Update procedure

Plan updates of KW devices for maintenance windows, because measurements are interrupted while the new image is activated.

Download the firmware image for the KW series from the Kestrel service portal and verify the signature before distributing it.

If an update of a KW device fails, the previous image stays active and the update can be repeated. Roll back through the service portal if necessary.

Devices of the KW series keep their configuration during an update. Create a configuration backup anyway before updating devices in the field.

## Security

Kestrel recommends restricting network access to KW devices to the control network and changing default user codes during commissioning.

Security fixes for the KW series are announced through the service portal and the customer newsletter.

Releases of the KW series are signed, and devices reject images with an invalid signature. Report suspected vulnerabilities to the Kestrel product security team.
