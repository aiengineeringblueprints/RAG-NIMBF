# Project Brief PRJ-233: Harbor Telemetry Pilot

Owner: Kestrel Instruments. Classification: internal.

## Background

Project PRJ-233, Harbor Telemetry Pilot, is delivered for Strandli Bygg AS.

Project PRJ-233 replaces manual readings with continuous monitoring, so that Strandli Bygg AS can react to deviations faster.

Strandli Bygg AS commissioned project PRJ-233 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

The goal of project PRJ-233 is to improve data quality and reduce maintenance effort for Strandli Bygg AS.

## Key information

Project code: PRJ-233. Customer: Strandli Bygg AS. Project lead: Nora Kruger. Delivery site: Aarhus. Product: Kestrel KP9. Start date: 2026-05-01. Final deadline: 2027-06-28.

The project is led by Nora Kruger and run from the Aarhus site. The solution is based on the Kestrel KP9.

## Scope

The scope of project PRJ-233 covers delivery, installation and commissioning of Kestrel KP9 devices and their integration into the customer's control system.

Civil works and cabling outside the measuring points are not part of project PRJ-233 and are provided by Strandli Bygg AS.

Optional services in project PRJ-233, such as extended support, are offered separately.

Project PRJ-233 includes training for the customer's maintenance staff and a documentation package for audits.

## Risk register

| Risk | Mitigation |
