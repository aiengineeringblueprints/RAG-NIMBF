# Kestrel KL9 Datasheet

Kestrel Instruments. Internal use only.

## Overview

The Kestrel KL9 is a level sensor sold under SKU KS-1028. It was launched in 2016.

The Kestrel KL9 is designed for continuous operation in demanding industrial environments. It combines a robust enclosure with a measurement core that Kestrel Instruments develops and calibrates in-house, so readings stay stable over long service intervals.

Every Kestrel KL9 leaves the factory with an individual test report. The report documents the final functional test and the configuration loaded before shipment, which simplifies acceptance testing on site.

## Mechanical installation

Orient the cable entries of the Kestrel KL9 downwards when installing outdoors, so that condensation cannot collect in the terminal compartment.

After mechanical installation, check that the Kestrel KL9 is firmly seated and that the housing cover closes without force.

## Electrical connection

Install a suitable fuse in the supply line of the Kestrel KL9 and protect the signal lines against surges where long cable runs leave the building.

Connect the protective earth of the Kestrel KL9 before connecting the supply. Check the polarity of all terminals against the wiring diagram on the inside of the cover.

## Maintenance

Do not use solvents or high-pressure cleaners on the Kestrel KL9; they can damage the seals and the sensing element.

Recalibrate the Kestrel KL9 according to the calibration procedure of Kestrel Instruments or send it to an accredited calibration lab.

## Diagnostics and troubleshooting

| Symptom | Possible cause | Remedy |
|---|---|---|
| Reading drifts slowly | Sensing element contaminated | Clean or recalibrate the device |
| Unstable reading | Electrical interference | Check shielding and cable routing |
| Alarm without cause | Alarm limits too tight | Review limits and hysteresis |
| Values frozen | Device in function-check mode | Leave service mode in the configurator |
| Condensation in housing | Cable entries facing upwards | Remount with entries facing down |

## FAQ

**Q:** Can I replace the sensing element of the Kestrel KL9 myself?
**A:** Only trained service staff should replace it, because the device must be recalibrated afterwards.

**Q:** Do I need special software for the Kestrel KL9?
**A:** No. The device works with standard control systems; the Kestrel Configurator is only needed for advanced settings.

**Q:** How is the Kestrel KL9 protected against unauthorised changes?
**A:** A user code can lock the configuration; without it settings can be read but not changed.

**Q:** Can the Kestrel KL9 be used outdoors?
**A:** Yes, provided the enclosure rating stated in the specification table matches the installation conditions and the cable entries face downwards.
