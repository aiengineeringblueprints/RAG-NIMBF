# Project Brief PRJ-231: Delta Monitoring Upgrade

Owner: Kestrel Instruments. Classification: internal.

## Context

Project PRJ-231, Delta Monitoring Upgrade, is delivered for Hedberg Foods GmbH.

The goal of project PRJ-231 is to improve data quality and reduce maintenance effort for Hedberg Foods GmbH.

Project PRJ-231 replaces manual readings with continuous monitoring, so that Hedberg Foods GmbH can react to deviations faster.

Hedberg Foods GmbH commissioned project PRJ-231 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

## Project data

Project code: PRJ-231. Customer: Hedberg Foods GmbH. Project lead: Maja Iversen. Delivery site: Oslo. Product: Kestrel KD2. Start date: 2025-11-14. Final deadline: 2026-11-19.

The project is led by Maja Iversen and run from the Oslo site. The solution is based on the Kestrel KD2.

The scope of project PRJ-231 covers delivery, installation and commissioning of Kestrel KD2 devices and their integration into the customer's control system.

Project PRJ-231 includes training for the customer's maintenance staff and a documentation package for audits.
