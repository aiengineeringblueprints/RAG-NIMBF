# Project Brief PRJ-223: Fjord Metering Upgrade

Kestrel Instruments. Internal use only.

## Background

Falkberg Logistics Oy commissioned project PRJ-223 (Fjord Metering Upgrade).

Project PRJ-223 replaces manual readings with continuous monitoring, so that Falkberg Logistics Oy can react to deviations faster.

The goal of project PRJ-223 is to improve data quality and reduce maintenance effort for Falkberg Logistics Oy.

## Budget

The initial estimate was 532000 EUR. After the scope review the steering committee approved a budget of 546500 EUR.

## Scope of delivery

The scope of project PRJ-223 covers delivery, installation and commissioning of Kestrel KT4 devices and their integration into the customer's control system.

Optional services in project PRJ-223, such as extended support, are offered separately.
