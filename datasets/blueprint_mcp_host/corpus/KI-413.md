# Project Brief PRJ-213: Delta Climate Control Expansion

Kestrel Instruments. Internal use only.

## Context

Aasen Mining Oy commissioned project PRJ-213 (Delta Climate Control Expansion).

The goal of project PRJ-213 is to improve data quality and reduce maintenance effort for Aasen Mining Oy.

Project PRJ-213 replaces manual readings with continuous monitoring, so that Aasen Mining Oy can react to deviations faster.

Aasen Mining Oy commissioned project PRJ-213 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

## Project facts

Project code: PRJ-213. Customer: Aasen Mining Oy. Project lead: Niklas Thomsen. Delivery site: Hamburg. Product: Kestrel KQ4. Start date: 2025-11-30. Final deadline: 2027-01-10.

The project is led by Niklas Thomsen and run from the Hamburg site. The solution is based on the Kestrel KQ4.

## Communication plan

Decisions in project PRJ-213 are documented in the decision log and confirmed by email.

Weekly calls between the project teams of Aasen Mining Oy and Kestrel keep project PRJ-213 on track between steering committee meetings.

Project PRJ-213 uses a shared workspace for documents, meeting minutes and open points.

## Goals

- Hand over a validated configuration backup
- Replace legacy instruments with current Kestrel devices
- Reduce manual inspection rounds
- Provide remote diagnostics for the service team
- Integrate all measuring points into the customer's control system

## Scope

Project PRJ-213 includes training for the customer's maintenance staff and a documentation package for audits.

Civil works and cabling outside the measuring points are not part of project PRJ-213 and are provided by Aasen Mining Oy.

The scope of project PRJ-213 covers delivery, installation and commissioning of Kestrel KQ4 devices and their integration into the customer's control system.

Optional services in project PRJ-213, such as extended support, are offered separately.

## Project organisation

Live figures of project PRJ-213 such as budget spent and percent complete are tracked in the project system, not in this brief.

A steering committee with representatives of Aasen Mining Oy and Kestrel meets at every milestone of project PRJ-213.

Status reports are shared with Aasen Mining Oy every two weeks. Change requests follow the standard change process and need written approval.
