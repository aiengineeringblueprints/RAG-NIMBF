# Project Brief PRJ-204: Northern Leak Detection Expansion

Kestrel Instruments. Internal use only.

## Introduction

Project PRJ-204, Northern Leak Detection Expansion, is delivered for Bergvik Marine Oy.

Project PRJ-204 replaces manual readings with continuous monitoring, so that Bergvik Marine Oy can react to deviations faster.

The goal of project PRJ-204 is to improve data quality and reduce maintenance effort for Bergvik Marine Oy.

Bergvik Marine Oy commissioned project PRJ-204 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

## Key information

Project code: PRJ-204. Customer: Bergvik Marine Oy. Project lead: Magnus Aune. Delivery site: Oslo. Product: Kestrel KQ2. Start date: 2026-04-15. Final deadline: 2027-07-23.

The project is led by Magnus Aune and run from the Oslo site. The solution is based on the Kestrel KQ2.

## Budget

The initial estimate was 626500 EUR. After the scope review the steering committee approved a budget of 654000 EUR.

## Scope

Civil works and cabling outside the measuring points are not part of project PRJ-204 and are provided by Bergvik Marine Oy.

The scope of project PRJ-204 covers delivery, installation and commissioning of Kestrel KQ2 devices and their integration into the customer's control system.

Project PRJ-204 includes training for the customer's maintenance staff and a documentation package for audits.

Optional services in project PRJ-204, such as extended support, are offered separately.
