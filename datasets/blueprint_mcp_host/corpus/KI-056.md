# KV Series Firmware Release Notes (vibration sensors)

Owner: Kestrel Instruments. Classification: internal.

## Introduction

The KV series shares one firmware code base, but each model receives its own signed image. Images cannot be exchanged between models.

These release notes list the firmware history of the KV series. Install the latest release unless a project specification requires a validated older version.

Firmware for the KV series is cumulative: every release contains all fixes of the earlier releases. Downgrades are possible but not recommended.

## Security

Kestrel recommends restricting network access to KV devices to the control network and changing default user codes during commissioning.

Releases of the KV series are signed, and devices reject images with an invalid signature. Report suspected vulnerabilities to the Kestrel product security team.

Security fixes for the KV series are announced through the service portal and the customer newsletter.

## Known issues

- Some diagnostic texts are only available in English.
- Older configurator versions show the firmware date in the wrong time zone.

## Compatibility notes

Configuration backups created with older KV firmware can be restored on newer releases; the reverse direction is not supported.

Firmware releases of the KV series keep the communication register map stable, so control system integrations do not need changes after an update.

All releases of the KV series work with the current Kestrel Configurator. Older configurator versions can read but not write settings of the latest firmware.

## Installing updates

Devices of the KV series keep their configuration during an update. Create a configuration backup anyway before updating devices in the field.

Plan updates of KV devices for maintenance windows, because measurements are interrupted while the new image is activated.

If an update of a KV device fails, the previous image stays active and the update can be repeated. Roll back through the service portal if necessary.

Download the firmware image for the KV series from the Kestrel service portal and verify the signature before distributing it.
