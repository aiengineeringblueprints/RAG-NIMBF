# Project Brief PRJ-202: Tidal Monitoring Rollout

Kestrel Instruments. Internal use only.

## Background

Project PRJ-202, Tidal Monitoring Rollout, is delivered for Aasen Bygg AS.

Project PRJ-202 replaces manual readings with continuous monitoring, so that Aasen Bygg AS can react to deviations faster.

The goal of project PRJ-202 is to improve data quality and reduce maintenance effort for Aasen Bygg AS.

Aasen Bygg AS commissioned project PRJ-202 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

## Project data

Project code: PRJ-202. Customer: Aasen Bygg AS. Project lead: Niklas Thomsen. Delivery site: Bergen. Product: Kestrel KP9. Start date: 2025-05-14. Final deadline: 2026-07-13.

The project is led by Niklas Thomsen and run from the Bergen site. The solution is based on the Kestrel KP9.

## Scope

Civil works and cabling outside the measuring points are not part of project PRJ-202 and are provided by Aasen Bygg AS.

Optional services in project PRJ-202, such as extended support, are offered separately.

Project PRJ-202 includes training for the customer's maintenance staff and a documentation package for audits.

## Risks

| Risk | Mitigation |
|---|---|
| Weather conditions for outdoor work | Schedule outdoor installation with buffer time |
| Interfaces to legacy systems | Run an interface test in the first project phase |
| Scope changes | Handle changes through the standard change process |

## Goals

- Provide remote diagnostics for the service team
- Replace legacy instruments with current Kestrel devices
- Hand over a validated configuration backup
- Reduce manual inspection rounds
