# Project Brief PRJ-208: Harbor Automation Expansion

Kestrel Instruments, internal document.

## Context

Project PRJ-208, Harbor Automation Expansion, is delivered for Rosen Pharma ApS.

The goal of project PRJ-208 is to improve data quality and reduce maintenance effort for Rosen Pharma ApS.

Project PRJ-208 replaces manual readings with continuous monitoring, so that Rosen Pharma ApS can react to deviations faster.

Rosen Pharma ApS commissioned project PRJ-208 to modernise measurement and monitoring at one of its sites. The existing equipment had reached the end of its service life.

## Project facts

- Project code: PRJ-208
- Customer: Rosen Pharma ApS
- Project lead: Sindre Jensen
- Delivery site: Stavanger
- Product: Kestrel KG2
- Start date: 2025-07-15
- Final deadline: 2026-05-10

The project is led by Sindre Jensen and run from the Stavanger site. The solution is based on the Kestrel KG2.

The initial estimate was 563000 EUR. After the scope review the steering committee approved a budget of 537500 EUR.

## Project organisation

Status reports are shared with Rosen Pharma ApS every two weeks. Change requests follow the standard change process and need written approval.

A steering committee with representatives of Rosen Pharma ApS and Kestrel meets at every milestone of project PRJ-208.

Live figures of project PRJ-208 such as budget spent and percent complete are tracked in the project system, not in this brief.

## Goals

- Replace legacy instruments with current Kestrel devices
- Integrate all measuring points into the customer's control system
- Provide remote diagnostics for the service team
- Document the installation for later audits

## Scope of delivery

Project PRJ-208 includes training for the customer's maintenance staff and a documentation package for audits.

The scope of project PRJ-208 covers delivery, installation and commissioning of Kestrel KG2 devices and their integration into the customer's control system.

Optional services in project PRJ-208, such as extended support, are offered separately.

Civil works and cabling outside the measuring points are not part of project PRJ-208 and are provided by Rosen Pharma ApS.
