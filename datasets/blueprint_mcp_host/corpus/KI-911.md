# Kestrel KV5-L Discontinuation Notice

Owner: Kestrel Instruments. Classification: internal.

The Kestrel KV5-L, predecessor of the Kestrel KV5, was discontinued in 2023. The KV5-L had a maximum operating temperature of 65 °C. It used SKU KS-0900 and is no longer stocked.

## Migration

Customers still operating a KV5-L should plan the migration to the Kestrel KV5. The successor uses the same mounting dimensions, but wiring and configuration must be checked against its current datasheet before replacement.

- Check the current datasheet of the successor
- Order mounting adapters if needed
- Back up the existing configuration
- Plan the replacement in a maintenance window
