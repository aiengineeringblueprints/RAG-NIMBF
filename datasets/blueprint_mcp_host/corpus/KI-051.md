# KH Series Firmware Release Notes (humidity sensors)

Kestrel Instruments, internal document.

## Scope of this document

These release notes list the firmware history of the KH series. Install the latest release unless a project specification requires a validated older version.

Firmware for the KH series is cumulative: every release contains all fixes of the earlier releases. Downgrades are possible but not recommended.

## Known issues

- The event list is cleared after a factory reset.
- Readings may pause briefly after a configuration import.
- Older configurator versions show the firmware date in the wrong time zone.
- Some diagnostic texts are only available in English.

## Security information

Kestrel recommends restricting network access to KH devices to the control network and changing default user codes during commissioning.

Security fixes for the KH series are announced through the service portal and the customer newsletter.

## Compatibility notes

Firmware releases of the KH series keep the communication register map stable, so control system integrations do not need changes after an update.

All releases of the KH series work with the current Kestrel Configurator. Older configurator versions can read but not write settings of the latest firmware.
